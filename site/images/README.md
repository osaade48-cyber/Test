# Photos

Drop JPGs into this folder with these exact names and they appear on the site automatically.
Until a photo is added, a green placeholder shows in its place.

Aim for landscape photos about 1600px wide, compressed under ~400 KB (squoosh.app works well).

| File | Where it shows |
|---|---|
| hero.jpg | Home page, full-screen banner (your best project shot) |
| hero-services.jpg, hero-projects.jpg, hero-about.jpg, hero-contact.jpg | Banners at the top of each page |
| about-team.jpg | Team / owner photo (Home + About) |
| service-design.jpg, service-paving.jpg, service-gardens.jpg, service-decking.jpg, service-irrigation.jpg, service-maintenance.jpg | Service cards and Services page |
| project-1.jpg … project-9.jpg | Projects gallery (titles are set in the HTML) |
| og-image.jpg | Preview image when the site is shared on social media (1200×630) |
